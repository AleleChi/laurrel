# LAURREL SERVICES — ANTIGRAVITY PHASE 01 STARTER

## Quick start

1. Extract this ZIP into the Antigravity project **root** (not as an extra nested folder), preserving `public/assets/...` and `references/...`.
2. Open Antigravity with the project root selected.
3. In the Agent chat, paste the entire contents of `PASTE_THIS_IN_ANTIGRAVITY.md`.
4. Let the agent plan briefly, build the website, run the development server, and screenshot the desktop/mobile site.
5. Bring the real browser screenshots back for review. Don't move to the next section yet.

This contains genuine logo/room assets, design references, and a build prompt. The provided UI visual is a mockup, not an implemented website. If you later receive the actual Flow hero video, save it at `public/assets/hero/laurrel-hero.mp4` and have the agent integrate it.
